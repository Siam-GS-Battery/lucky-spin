Apps Script

หน้านี้อ่านรายชื่อและเขียนผล played กับรางวัลกลับลง Google Sheet ผ่าน Apps Script ของชีตนั้น

รีเฟรชอัตโนมัติ
ดึงรายชื่อใหม่ทุก 20 วินาที

คอลัมน์ที่ต้องมีในแถวแรก

  1. เปิด Google Sheet เลือก ส่วนขยาย › Apps Script
  2. วางโค้ดจากไฟล์ Code.gs แล้วบันทึก
  3. ทำให้ใช้งานได้ › การทำให้ใช้งานได้รายการใหม่ › เว็บแอป
  4. ตั้ง "เรียกใช้ในฐานะ" เป็นตัวคุณ และ "ผู้มีสิทธิ์เข้าถึง" เป็นทุกคน
  5. คัดลอก URL ที่ลงท้าย /exec มาวางด้านซ้าย
