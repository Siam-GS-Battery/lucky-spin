## ผู้เล่น (Player)

### US-001: ชื่อขึ้นบนวงล้อภายใน 20 วินาที

**Story**: As a player, I want to see my name on the wheel within 20 seconds after I submit the Form, so that I can spin right after getting my stamp

| AC ID | Scenario | Given | When | Then | Status |
|---|---|---|---|---|---|
| AC-001-01 | ชื่อใหม่ขึ้นเอง (เดิม AC-01) | หน้า Select ของบูธ A เปิดอยู่ | มีแถวใหม่ในแท็บ `Auto Feedback` ที่ `ข้อมูลติดต่อ` = "สมชาย ใจดี" | "สมชาย ใจดี" ปรากฏในรายชื่อภายใน 20 วินาทีโดยไม่ต้องกดอะไร | To Do |
| AC-001-02 | จับคู่คอลัมน์ของ Form | แท็บมีหัวคอลัมน์ตัวพิมพ์ต่างกันและลำดับสลับ | โหลดรายชื่อ | ชื่อมาจาก `ข้อมูลติดต่อ` บริษัทมาจาก `บริษัท` และ id ของแถวที่ 5 คือ `row-5` | To Do |
| AC-001-03 | ข้ามแถวไม่มีชื่อ | แถวที่ 7 มี `ข้อมูลติดต่อ` ว่าง | โหลดรายชื่อ | แถวที่ 7 ไม่อยู่ในรายชื่อ | To Do |
| AC-001-04 | ไม่รีเฟรชระหว่างหมุน | วงล้อกำลังหมุนหรือเปิดรางวัลอยู่ | ครบรอบ 20 วินาที | ไม่มีการโหลดรายชื่อจนกว่าจะกลับ Select | To Do |

### US-002: แตะแล้ววงล้อหมุนทันที

**Story**: As a player, I want to tap the centre of the wheel and see it start spinning at once, so that the game feels responsive and exciting

| AC ID | Scenario | Given | When | Then | Status |
|---|---|---|---|---|---|

| AC-002-02 | แตะซ้ำ | วงล้อกำลังหมุน | แตะปุ่มหมุนอีก 3 ครั้ง | ไม่มีคำขอหมุนเพิ่ม | To Do |
| AC-002-03 | ปิดปุ่มระหว่างหมุน | วงล้อกำลังหมุน | กด "เปลี่ยนชื่อ" หรือ "แอดมิน" | ไม่มีผล ปุ่มแสดงเป็น disabled | To Do |

### US-003: เข็มหยุดตรงรางวัลที่ได้

**Story**: As a player, I want to see the pointer stop on the prize I actually receive, so that I trust the result on screen

| AC ID | Scenario | Given | When | Then | Status |
|---|---|---|---|---|---|
| AC-003-01 | หยุดตรงช่อง (เดิม AC-02 ปรับ) | Backend คืนรางวัล "กระเป๋าผ้า" | วงล้อหยุด | เข็มชี้ในช่องกระเป๋าผ้าที่ตำแหน่ง 18–82% ของความกว้างช่อง และฉากเปิดรางวัลแสดง "กระเป๋าผ้า" | To Do |
| AC-003-02 | รางวัลไม่อยู่บนวงล้อปัจจุบัน | วงล้อที่แสดงอยู่ไม่มีช่องกระบอกน้ำ | Backend คืน "กระบอกน้ำ" พร้อมสถานะวงล้อใหม่ | วงล้อวาดช่องใหม่ก่อนหยุด และเข็มหยุดในช่องกระบอกน้ำ | To Do |
| AC-003-03 | ระยะเวลาและจำนวนรอบ | ตั้งระยะเวลาหมุน 7 วินาที | ได้ผลจาก backend | วงล้อหมุนอย่างน้อย 5 รอบ และหยุดภายใน 7 ± 0.5 วินาทีหลังได้ผล | To Do |

### US-004: ฉากเปิดรางวัล

## ทีมงานบูธ (Booth Staff)

**Story**: As a booth staff member, I want to log in with the shared username and password and pick booth A or B, so that only staff can run the wheel

| AC ID | Scenario | Given | When | Then | Status |
|---|---|---|---|---|---|
| AC-010-01 | Login สำเร็จ | อยู่หน้า login | กรอก username/password ถูก เลือกบูธ A แล้วกด "เข้าสู่ระบบ" | Redirect ไป `/?booth=A` และได้ cookie `HttpOnly; SameSite=Strict` อายุ 4 ชั่วโมง | To Do |
| AC-010-02 | รหัสผิด | อยู่หน้า login | กรอกรหัสผิด | กลับหน้า login พร้อมข้อความรหัสผิด บูธที่เลือกยังถูกเลือกไว้ ไม่มี cookie | To Do |
| AC-010-03 | ไม่เลือกบูธ | อยู่หน้า login | กด "เข้าสู่ระบบ" โดยไม่เลือกบูธ | แสดงข้อความให้เลือกบูธ ไม่มี cookie | To Do |

## Non-Functional Acceptance Criteria (Checklist)

#### Performance:
- [ ] NFR-001: หมุนเฉลี่ย ≥ 55 fps บนโน้ตบุ๊กการ์ดจอในตัว pixel ratio ≤ 2
- [ ] NFR-002: ซ่อนแท็บหรือเปิดหน้าแอดมินแล้วไม่มี frame ถูก render
- [ ] NFR-003: พิมพ์ค้นหาใน 500 รายชื่อ แสดงผลภายใน 100 ms
- [ ] NFR-004: Endpoint ที่ไม่เรียก Apps Script P95 < 2 วินาที, `/api/spin` และ `/api/players` P95 < 5 วินาที (รอ Q5)

#### Security:
- [ ] NFR-008: ชื่อผู้เล่น `<img src=x onerror=alert(1)>` แสดงเป็นข้อความ ไม่รันสคริปต์ (ทั้งแท็บบูธและแท็บ `Prizes`)
- [ ] NFR-009 / NFR-010: ไม่มี secret ใน repo, bundle หรือ response; Apps Script ปฏิเสธ token ผิด
- [ ] NFR-011: Body ผิด schema ตอบ 400 พร้อม `errors`; body > 10 KB ตอบ 413; ทุก response ใช้รูปแบบมาตรฐาน SOP
- [ ] NFR-012: ทุก response มี `Cache-Control: no-store`, `X-Frame-Options: DENY`, `X-Content-Type-Options: nosniff`
- [ ] NFR-013 / NFR-015: `alg: none`, ลายเซ็นผิด, หมดอายุ ถูกปฏิเสธ; redirect ไปได้เฉพาะ `/?booth=<บูธใน session>`
- [ ] NFR-014: 5xx ไม่มีข้อความภายใน
- [ ] NFR-016: `/api/spin` ครั้งที่ 11 ในนาทีเดียวกันของ session เดียวตอบ 429
- [ ] NFR-021: Log ของ server ไม่มีอีเมลหรือ feedback

#### Integration / Deployment / Quality:
- [ ] NFR-017: Timeout ไป Apps Script 25 วินาที; POST ครอบ `LockService` 15 วินาที
- [ ] NFR-018 / NFR-019: `docker compose up --build` และ Railway ใช้งานได้ตาม AC-042-01 ถึง AC-042-03
- [ ] NFR-020: lint, type-check, test, build ผ่าน; coverage BE ≥ 80%, FE ≥ 70%

#### Usability / Accessibility / Compatibility:
- [ ] NFR-005: ผ่าน flow หลักบน Chrome, Edge, Safari ล่าสุด (เดสก์ท็อปและ iPad)
- [ ] NFR-006 / NFR-007: ผ่าน AC-008-01 ถึง AC-008-03; ข้อความ contrast ผ่าน WCAG AA
- [ ] NFR-023: Runbook ของงานระบุห้ามเรียง แทรก หรือลบแถวในแท็บบูธ
