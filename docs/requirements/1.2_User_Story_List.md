# 1.2 User Story List

| รายการ | รายละเอียด |
|---|---|
| โปรเจกต์ | Lucky Draw วงล้อนำโชค |

| สถานะ | Draft รอ Product Owner อนุมัติ |

**บทบาท (User Type)**
- **ผู้เล่น (Player)** — ผู้เข้าชมบูธที่ส่ง Google Form แล้ว แตะหมุนเอง
- **ทีมงานบูธ (Booth Staff)** — ผู้ช่วยบูธ login เครื่องวงล้อ แตะชื่อผู้เล่น เข้าโหมดแอดมินด้วย PIN
- **ผู้จัดงาน (Event Organiser)** — ตั้งค่ารางวัลใน Sheet ดูแลสต็อก ดูแลการ deploy

Story Points ประเมินโดย PM รอ senior + junior ยืนยันใน Planning Poker (DoR ข้อ 4) งานทดสอบของทุก story เป็นของ `qa` (ดู [task.md](task.md))
